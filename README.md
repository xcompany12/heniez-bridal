# Heniez Bridal

Website butik gaun pengantin. Remake dari versi Laravel lama, dibangun dengan Next.js (App Router), TypeScript, dan Tailwind CSS. Dipublish di Vercel.

## Menjalankan di komputer

Butuh Node.js 18.18 atau lebih baru.

```bash
npm install
npm run dev
```

Buka http://localhost:3000

## Struktur

- `app/` halaman dan layout (App Router)
- `components/` komponen UI (Header, Footer, dst.)
- `lib/site.ts` nama brand dan menu navigasi
- `tailwind.config.ts` token desain (warna, font)
- `app/globals.css` gaya dasar dan kelas bersama (`container-site`, `btn-dark`, `btn-outline`)
